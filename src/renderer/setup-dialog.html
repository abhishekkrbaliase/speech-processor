Google Speech-to-Text Setup

Configure your Google Cloud credentials to enable speech recognition

1 Create Service Account

Go to Google Cloud Console → Credentials

Click + CREATE CREDENTIALS → Service account

Add role: Cloud Speech Client

2 Download JSON Key

Click on service account → Keys tab → ADD KEY → Create new key → JSON

3 Upload Credentials File

Select the downloaded JSON credentials file

4 Save Configuration

Your service account credentials will be saved securely in the application.

💡 Alternative: You can also set the environment variable GOOGLE_APPLICATION_CREDENTIALS

🔒 Security: Your credentials are stored locally and never shared

✅ More Secure: Service accounts are more secure than API keys
