# Icon Creation Guide

To complete the build setup, you need to create application icons:

## Required Icon Files

### macOS (.icns)
- **File**: `icon.icns`
- **Sizes**: 16x16, 32x32, 128x128, 256x256, 512x512, 1024x1024
- **Tool**: Use `iconutil` on macOS or online converters

### Windows (.ico)
- **File**: `icon.ico`
- **Sizes**: 16x16, 32x32, 48x48, 256x256
- **Tool**: Use online ICO converters or GIMP

### Source PNG
- **File**: `icon.png`
- **Size**: 1024x1024 (recommended)
- **Format**: PNG with transparency

## Quick Creation Steps

1. Create a 1024x1024 PNG icon representing your app
2. Use online tools to convert:
   - PNG to ICNS: https://cloudconvert.com/png-to-icns
   - PNG to ICO: https://cloudconvert.com/png-to-ico
3. Place the files in this directory

## Design Guidelines

- Use a simple, recognizable design
- Ensure it looks good at small sizes (16x16)
- Use your brand colors
- Consider a microphone or speech bubble theme
- Maintain good contrast

## Example Icon Concept

For a speech overlay app, consider:
- Microphone icon with overlay elements
- Speech bubble with waveform
- Medical cross with audio waves
- Simple geometric design with app initials
